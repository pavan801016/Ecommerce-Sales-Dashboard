E-commerce Sales Analysis Dashboard

Project Overview
This project focuses on analyzing e-commerce sales data to understand sales performance, profit, customer behavior, and product trends. The dashboard provides meaningful insights through interactive visualizations to support better business decisions.

Objectives
- Analyze overall sales and profit performance.
- Identify top-selling products and categories.
- Understand customer purchasing trends.
- Track sales performance over time.
- Identify profitable and underperforming areas.
- Support data-driven business decisions.

Tools & Technologies
- Power BI – Dashboard creation and data visualization.
- Microsoft Excel – Data cleaning and preparation.
- DAX – Calculated measures and KPIs in Power BI, if used.

Key Performance Indicators (KPIs)
The dashboard can track the following metrics:
- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Profit Margin


Dashboard Features
- Sales Analysis: Track overall sales performance.
- Profit Analysis: Evaluate profitability.
- Product Analysis: Identify top-performing products.
- Category Analysis: Compare sales across product categories.
- Time-Based Analysis: Monitor sales trends over time.
- Interactive Filters: Explore data using available slicers and filters.

Key Insights
The dashboard can help identify:
- Products and categories generating the highest sales.
- Trends in sales and profit over time.
- Areas with strong or weak business performance.
- Opportunities to improve sales and profitability.
